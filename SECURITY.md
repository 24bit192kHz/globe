# Security Policy

## Reporting a vulnerability

Report security issues privately via
[GitHub security advisories](https://docs.github.com/en/code-security/security-advisories)
for this repository. Do not open a public issue — a rendering bug is not a
vulnerability, but a private report still gets read.

Scope is this repository only (the `globe` library, `globe-cli`, and the
`tools/` baker). Upstream dependencies, terminal emulators, and the Solar
System Scope source imagery are out of scope.

## What to expect

- Acknowledgement of your report.
- A fix in the `Unreleased` section of `CHANGELOG.md` once one lands,
  with credit if you want it.

There is no bug bounty — this is an unpaid hobby project.
